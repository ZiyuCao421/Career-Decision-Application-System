# CAMP：职业决策与求职知识库

> Career Application & Market Platform

CAMP 是一个由个人主导、AI 辅助的轻量级求职管理、市场研究与职业决策知识库。它以 Markdown 与 CSV 为基础，持续记录岗位、企业、市场信号、投递反馈和面试经验，为 2026 年秋招至 2027 年毕业的职业决策积累可追溯证据。

## 使用原则

- **个人主导**：是否投递、如何沟通、接受何种 offer，均由本人确认；本库不自动投递、不发送招聘消息、不代表本人作出承诺。
- **事实可追溯**：重要信息记录来源、URL、核查日期、摘要、置信度与备注，并区分已核实事实、未核实信息、个人观点与传闻。
- **轻量优先**：先记录真正影响决定的信息；单个岗位的初步调查目标控制在 30 分钟内。
- **地区适配**：中国大陆和新加坡的币种、企业登记、合同主体和工作准证等信息独立记录，不相互混用。
- **隐私优先**：不提交简历原件、身份证件、密码、Token、私人联系方式或不必要的招聘方个人信息。

## 当前求职策略：海投阶段

当前处于**海投阶段**，首要目标是提高获得一面机会的效率，而不是用不完整的信息过早收窄候选池。岗位评价是辅助决策，不是自动淘汰机制：

1. 先以岗位方向、基本门槛、地点和可接受条件决定是否进入候选池；
2. 用“个人匹配度”安排准备优先级，而非要求完美匹配才投递；
3. 将“岗位安全评估”作为独立底线检查。仅明确的高风险信号应触发暂停或进一步核实；
4. 随投递反馈、毕业时间和可用机会变化，在后续阶段动态调整策略与权重。

详见 [`00_SYSTEM/evaluation_matrix.md`](00_SYSTEM/evaluation_matrix.md) 和 [`00_SYSTEM/workflow.md`](00_SYSTEM/workflow.md)。

## 目录

| 目录 | 用途 |
|---|---|
| `00_SYSTEM/` | 工作流、评分体系、调查清单、字段字典与更新规则 |
| `01_PROFILE/` | 经本人确认的职业资料、技能与项目经历 |
| `02_APPLICATIONS/` | 岗位索引与逐岗位投递档案 |
| `03_COMPANIES/` | 企业主体、调查证据与风险记录 |
| `04_MARKET/` | 按地区沉淀的岗位与技能市场观察 |
| `05_INTERVIEWS/` | 笔试、面试与复盘记录 |
| `06_ANALYTICS/` | 漏斗快照与周度复盘 |
| `07_AI_READY/` | 后续 RAG 与 AI 辅助所需的检索规则和知识分类 |

## 快速开始

1. 在 `01_PROFILE/` 补充已确认的技能和项目，不填写或上传不希望存储的信息。
2. 在 `02_APPLICATIONS/application_index.csv` 建立 `APP-####`，再从 `records/README_TEMPLATE.md` 建立岗位档案。
3. 在 `03_COMPANIES/company_index.csv` 建立或关联 `COMP-####`，把证据写入企业档案和岗位调查页。
4. 记录每次筛选、笔试、面试或结果，并在每周复盘中只基于可追溯记录总结结论。
